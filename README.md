# Jumia Sales Analysis Dashboard

## Project Overview

This project presents an interactive Power BI dashboard designed to analyze Jumia's sales performance, profitability, delivery operations, and marketing effectiveness. The dashboard transforms raw business data into meaningful insights through interactive reports and KPIs to support strategic decision-making.

---

## Project Objectives

- Analyze sales performance.
- Monitor profitability.
- Evaluate product category performance.
- Compare brand sales.
- Track delivery efficiency.
- Analyze marketing campaign performance.
- Support business decisions through interactive dashboards.

---

## Tools Used

- Power BI
- Power Query
- DAX
- Data Modeling
- Excel

---

### Marketing Analysis
